

## 🧪 Python Lab – Collections + For Loop + Range

### Part 1 – Lists

1. Create a list of 5 Indian city names.

   * Print each city using a `for` loop.
2. Add one more city to the list.

   * Print the updated list.
3. Use `range()` to print the index and city name together.

---

### Part 2 – Tuples

1. Create a tuple with 5 fruit names.
2. Write a loop to print all fruits in uppercase.
3. Challenge: Try to add a fruit to the tuple. What happens? Why?

---

### Part 3 – Dictionaries

1. Create a dictionary with **3 students and their marks**. Example:

   ```python
   marks = {"Anita": 85, "Ravi": 90, "Meena": 78}
   ```
2. Use a loop to print names of students who scored more than 80.
3. Challenge: Find the student with the **highest marks**.

---

### Part 4 – Sets

1. Create two sets:

   * `set1 = {1, 2, 3, 4, 5}`
   * `set2 = {4, 5, 6, 7, 8}`
2. Print:

   * The union of both sets
   * The intersection of both sets
   * The difference `set1 - set2`
3. Challenge: Write a loop to print numbers from 1–10, and store only **odd numbers** in a set.

---

### Part 5 – Mini Challenge (Mixing Concepts)

1. Create a list of numbers from 1–20 using `range()`.
2. Loop through the list and:

   * Store even numbers in one list
   * Store odd numbers in another list
3. Finally, print both lists.
