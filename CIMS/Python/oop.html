Object-Oriented Programming (OOP) in Python

This page covers the core OOP concepts in Python: Classes, Objects, Constructors, Inheritance, Polymorphism, Encapsulation, and Abstraction.

1. Classes

A class is a blueprint or template used to create objects. It defines the attributes (data) and methods (behavior) that the objects created from the class will have.

  • A class groups related data and functions together.
  • It helps organize code in a structured and reusable way.
  • It acts as a design for real-world entities such as Student, Car, BankAccount, etc.
Example: Defining a Class
class Student:
    college = "ABC College"   # class attribute

    def study(self):
        print("Student is studying")
Key idea: A class is the design; objects are the actual things created from that design.

2. Objects

An object is an instance of a class. Once a class is created, we can create multiple objects from it. Each object can hold its own data.

  • Objects represent real-world entities.
  • Each object can have different values for its attributes.
  • Objects can call the methods defined inside the class.
Example: Creating Objects
class Student:
    def study(self):
        print("Student is studying")

s1 = Student()
s2 = Student()

s1.study()
s2.study()
Key idea: If Student is a class, then s1 and s2 are objects of that class.

3. Constructors

A constructor is a special method that runs automatically when an object is created. In Python, the constructor is written using __init__().

  • Used to initialize object data.
  • Allows each object to start with different values.
  • Commonly used to assign values to instance variables.
Example: Constructor in Python
class Student:
    def __init__(self, name, marks):
        self.name = name
        self.marks = marks

    def display(self):
        print("Name:", self.name)
        print("Marks:", self.marks)

s1 = Student("Amit", 88)
s1.display()
Key idea: __init__() helps set up the object with initial values when it is created.

4. Inheritance

Inheritance allows one class to acquire the properties and methods of another class. The existing class is called the parent/base class, and the new class is called the child/derived class.

  • Promotes code reuse.
  • Helps build relationships between classes.
  • A child class can use parent features and also add its own features.
Example: Inheritance
class Person:
    def show_person(self):
        print("I am a person")

class Student(Person):
    def show_student(self):
        print("I am a student")

s = Student()
s.show_person()
s.show_student()
Key idea: The child class can reuse the methods of the parent class.

5. Polymorphism

Polymorphism means “many forms”. The same method name can behave differently depending on the object or context.

  • One interface, multiple implementations.
  • Makes code flexible and scalable.
  • Commonly seen in method overriding.
Example: Polymorphism using Method Overriding
class Animal:
    def sound(self):
        print("Animal makes a sound")

class Dog(Animal):
    def sound(self):
        print("Dog barks")

class Cat(Animal):
    def sound(self):
        print("Cat meows")

a1 = Dog()
a2 = Cat()

a1.sound()
a2.sound()
Key idea: The same method sound() behaves differently for Dog and Cat.

6. Encapsulation

Encapsulation means wrapping data and methods into a single unit (class) and controlling direct access to data.

  • Protects object data from accidental modification.
  • Improves security and maintainability.
  • In Python, private members are indicated using double underscore __.
Example: Encapsulation
class BankAccount:
    def __init__(self, balance):
        self.__balance = balance   # private variable

    def deposit(self, amount):
        self.__balance += amount

    def get_balance(self):
        return self.__balance

acc = BankAccount(5000)
acc.deposit(2000)
print("Balance:", acc.get_balance())
Key idea: Data is hidden inside the class and accessed using methods like get_balance().

7. Abstraction

Abstraction means showing only the important features and hiding internal implementation details. It focuses on what an object does instead of how it does it.

  • Reduces complexity.
  • Improves code design and readability.
  • In Python, abstraction is often implemented using the ABC module.
Example: Abstraction using Abstract Class
from abc import ABC, abstractmethod

class Vehicle(ABC):
    @abstractmethod
    def start(self):
        pass

class Car(Vehicle):
    def start(self):
        print("Car starts with a key or button")

c = Car()
c.start()
Key idea: The abstract class defines what must be done, while the child class provides the actual implementation.

OOP Summary

  • Class → Blueprint for creating objects
  • Object → Instance of a class
  • Constructor → Initializes object data using __init__()
  • Inheritance → One class acquires properties of another class
  • Polymorphism → Same method behaves differently for different objects
  • Encapsulation → Protecting data by wrapping it inside a class
  • Abstraction → Hiding implementation and showing essential features only
