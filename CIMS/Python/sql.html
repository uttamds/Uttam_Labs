Topic 1 - Introduction to Databases

Understand what a database is and why almost every application needs one

What is a Database?

A database is an organized collection of data stored in a structured way so that it can be easily inserted, searched, updated and deleted.

Why use a database?

To store application data permanently instead of losing it when the program closes.

Where is it used?

Banking apps, e-commerce websites, hospital systems, school portals, payroll systems and many more.

What can it store?

Customer records, product details, employee data, marks, transactions, login details and more.

Important Database Terms

Table

A table stores data in rows and columns. Example: Student table, Employee table.

Row / Record

One complete entry in a table. Example: one student’s data.

Column / Field

A property or attribute of data. Example: name, age, salary, marks.

Primary Key

A unique column used to identify each row in a table.

Example Table: Student

student_id name course marks
101 Aarav Python 82
102 Diya SQL 88
103 Rohan Java 79
Observation: In the table above, student_id can act as the Primary Key because it uniquely identifies each student.

Database in Real Life Applications

  • Online Shopping: products, orders, payments, customers
  • College Management: students, faculty, attendance, marks
  • Banking: accounts, transactions, balance details
  • Hospital System: patients, doctors, appointments, bills
  • HR / Payroll: employees, salary, leaves, departments

Topic 2 - SQL Basics

SQL is the language used to work with relational databases

What is SQL?

SQL stands for Structured Query Language. It is used to create tables, insert data, retrieve data, update data and delete data from a relational database.

Create

Used to create database objects like tables.

Insert

Used to add new records into a table.

Select

Used to fetch or display data from a table.

Update / Delete

Used to modify existing records or remove records.

Basic SQL Commands

1) CREATE TABLE

CREATE TABLE student ( student_id INTEGER PRIMARY KEY, name TEXT, course TEXT, marks INTEGER );

2) INSERT INTO

INSERT INTO student (student_id, name, course, marks) VALUES (101, 'Aarav', 'Python', 82);

3) SELECT

SELECT * FROM student;

4) UPDATE

UPDATE student SET marks = 90 WHERE student_id = 101;

5) DELETE

DELETE FROM student WHERE student_id = 101;

Important SQL Keywords to Remember

SELECT

Reads data from a table.

FROM

Specifies the table from which data must be read.

WHERE

Applies a condition while selecting, updating or deleting data.

ORDER BY

Sorts the result in ascending or descending order.

Examples

SELECT name, marks FROM student; SELECT * FROM student WHERE marks > 80; SELECT * FROM student ORDER BY marks DESC;

Topic 3 - CRUD Operations

CRUD is the foundation of almost every database application

What is CRUD?

CRUD stands for:

  • C - Create → add new data
  • R - Read → fetch or view data
  • U - Update → modify existing data
  • D - Delete → remove data
CRUD Operation Meaning SQL Command
Create Add a new record INSERT
Read Fetch data SELECT
Update Change existing data UPDATE
Delete Remove data DELETE

CRUD Example on Student Table

Create

INSERT INTO student VALUES (104, 'Meera', 'MySQL', 85);

Read

SELECT * FROM student;

Update

UPDATE student SET course = 'Database' WHERE student_id = 104;

Delete

DELETE FROM student WHERE student_id = 104;

Topic 4 - SQLite and MySQL

Understand the difference between a lightweight database and a database server

What is SQLite?

SQLite is a lightweight, file-based relational database. It stores the entire database in a single file. It is very useful for beginners, local applications, mini projects and testing.

File-based

No separate server is required. Database is stored in a file like college.db.

Simple to use

Good for student practice, Python mini projects and small applications.

Built into Python

Python has the sqlite3 module, so no extra installation is needed in many cases.

What is MySQL?

MySQL is a popular relational database management system used in real-world web applications and enterprise systems. It works as a database server and can store large amounts of data.

Server-based

MySQL runs as a database server and multiple users can connect to it.

Industry usage

Commonly used in websites, business systems, dashboards and backend applications.

Scalable

Suitable for larger applications than SQLite.

SQLite vs MySQL

Feature SQLite MySQL
Type File-based database Server-based database
Installation Very simple / often built into Python workflow Needs MySQL server installation
Best for Learning, small projects, local apps Real-world applications, multi-user systems
Performance for large apps Limited compared to MySQL Better suited for larger systems

Topic 5 - Connectivity using Python

Learn how Python programs connect to databases and perform CRUD operations

Python + Database Workflow

In Python, database operations usually follow this sequence:

  1. Import the database module
  2. Create a connection
  3. Create a cursor object
  4. Execute SQL statements
  5. Commit changes if needed
  6. Fetch data if required
  7. Close the connection
Key idea: Python acts like the application layer, while the database stores the data permanently.

Python Connectivity with SQLite

SQLite is the easiest database to start with in Python because Python provides the sqlite3 module.

Step 1: Create Connection

import sqlite3 con = sqlite3.connect("college.db") cur = con.cursor()

Step 2: Create Table

cur.execute(""" CREATE TABLE IF NOT EXISTS student ( student_id INTEGER PRIMARY KEY, name TEXT, course TEXT, marks INTEGER ) """) con.commit()

Step 3: Insert Data

cur.execute("INSERT INTO student VALUES (101, 'Aarav', 'Python', 82)") con.commit()

Step 4: Read Data

cur.execute("SELECT * FROM student") rows = cur.fetchall() for row in rows: print(row)

Step 5: Close Connection

con.close()

Complete SQLite Example in Python

import sqlite3 # 1. connect to database con = sqlite3.connect("college.db") cur = con.cursor() # 2. create table cur.execute(""" CREATE TABLE IF NOT EXISTS student ( student_id INTEGER PRIMARY KEY, name TEXT, course TEXT, marks INTEGER ) """) # 3. insert record cur.execute("INSERT INTO student VALUES (101, 'Aarav', 'Python', 82)") # 4. commit changes con.commit() # 5. fetch records cur.execute("SELECT * FROM student") rows = cur.fetchall() print("Student Records:") for row in rows: print(row) # 6. close connection con.close()

Python Connectivity with MySQL

To connect Python with MySQL, we typically use a connector package such as mysql-connector-python.

Install the connector

pip install mysql-connector-python

Sample MySQL Connection in Python

import mysql.connector con = mysql.connector.connect( host="localhost", user="root", password="your_password", database="college_db" ) cur = con.cursor() cur.execute("SELECT * FROM student") rows = cur.fetchall() for row in rows: print(row) con.close()
In MySQL, the database should already exist, and the MySQL server must be running before Python connects to it.
