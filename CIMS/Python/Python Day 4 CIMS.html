Python Advanced Concepts - Quick Reference

Modules

Definition: A module is a Python file containing functions, variables, and classes that can be reused.
Use Case: Organize code into reusable components.
Sample Code: # math_demo.py def greet(): print("Hello") # main.py import math_demo math_demo.greet()

Packages

Definition: A package is a collection of related modules organized in folders.
Use Case: Manage large applications with modular structure.
Sample Code: project/ └── utilities/ ├── __init__.py └── calc.py from utilities.calc import add

Exception Handling

Definition: Exception handling prevents program crashes by handling runtime errors.
Use Case: Validate user input and manage unexpected situations.
Sample Code: try: n = int(input("Number: ")) print(100/n) except ZeroDivisionError: print("Cannot divide by zero") except ValueError: print("Invalid input")

File Handling

Definition: Reading from and writing data to files.
Use Case: Store application data, logs, reports, and records.
Sample Code: with open("data.txt","w") as f: f.write("Hello Python") with open("data.txt","r") as f: print(f.read())

Lambda Functions

Definition: Anonymous one-line functions created using lambda keyword.
Use Case: Short functions used with sorting, map, filter, etc.
Sample Code: square = lambda x: x*x print(square(5))

Map()

Definition: Applies a function to every item in an iterable.
Use Case: Transform entire collections efficiently.
Sample Code: nums = [1,2,3,4] result = list(map( lambda x:x*x, nums )) print(result)

Filter()

Definition: Filters elements based on a condition.
Use Case: Extract matching records from collections.
Sample Code: nums = [1,2,3,4,5,6] even = list(filter( lambda x:x%2==0, nums )) print(even)

Reduce()

Definition: Reduces an iterable to a single value using cumulative computation.
Use Case: Calculate sum, product, maximum, etc.
Sample Code: from functools import reduce nums = [1,2,3,4] total = reduce( lambda a,b:a+b, nums ) print(total)
