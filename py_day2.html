Conditional Statements

Conditional statements allow a program to make decisions based on whether a condition is True or False.

  • if
  • if...else
  • if...elif...else
  • Nested if
Use conditional statements whenever the program needs to choose between multiple paths. 
age = 18

if age >= 18:
    print("Eligible to vote")
else:
    print("Not eligible")

Loops

Loops are used to execute a block of code repeatedly.

  • for loop
  • while loop
Loops help avoid writing the same code multiple times. 
for i in range(1, 6):
    print(i)

count = 1

while count <= 5:
    print(count)
    count += 1

Loop Control Statements

  • break - Exit the loop immediately
  • continue - Skip current iteration
  • pass - Placeholder statement
for i in range(1, 10):
    if i == 5:
        break
    print(i)

Nested Loops

A loop inside another loop is called a nested loop.

Commonly used for patterns, tables, matrices, and grids. 
for row in range(3):
    for col in range(4):
        print("*", end=" ")
    print()

Output: 

* * * *
* * * *
* * * *

Functions

A function is a reusable block of code designed to perform a specific task.

  • Improves code readability
  • Reduces duplication
  • Makes maintenance easier
def greet():
    print("Welcome to Python")

greet()

Advantages of Functions

  • Code Reusability
  • Better Organization
  • Easier Testing
  • Reduced Complexity
  • Improved Maintenance

Arguments

Arguments are values passed to a function when it is called.

Functions become more flexible when they accept arguments. 
def greet(name):
    print("Hello", name)

greet("Ravi")
greet("Anita")

Types of Arguments

  • Positional Arguments
  • Keyword Arguments
  • Default Arguments
  • Variable-Length Arguments
def show_city(city="Bangalore"):
    print(city)

show_city()
show_city("Mysuru")

Return Values

Functions can send a value back to the caller using the return keyword. 

def add(a, b):
    return a + b

result = add(10, 20)

print(result)
return ends the function execution and sends a result back.

Variable Scope

Scope determines where a variable can be accessed within a program.

  • Local Scope
  • Global Scope

Local Scope

A variable created inside a function is local to that function. 

def show():
    message = "Python"

    print(message)

show()
Local variables cannot be accessed outside the function.

Global Scope

A variable declared outside all functions is called a global variable. 

course = "Python"

def display():
    print(course)

display()
Global variables can be accessed from multiple functions.

Local vs Global Variables

Local Variable Global Variable
Created inside a function Created outside functions
Accessible only within function Accessible throughout program
Temporary lifetime Exists until program ends

Challenge 1: Reverse a Number

Write a program to reverse the digits of a number. 

num = 12345

reverse = 0

while num > 0:
    digit = num % 10
    reverse = reverse * 10 + digit
    num = num // 10

print("Reversed Number =", reverse)
Input: 12345
Output: 54321

Challenge 2: Check if a Number is Palindrome

A palindrome number remains the same when reversed. 

num = 121
original = num

reverse = 0

while num > 0:
    digit = num % 10
    reverse = reverse * 10 + digit
    num = num // 10

if original == reverse:
    print("Palindrome")
else:
    print("Not Palindrome")
Examples:
121 → Palindrome
1331 → Palindrome
123 → Not Palindrome

Challenge 9: Factorial Using Function

def factorial(n):
    result = 1

    for i in range(1, n + 1):
        result *= i

    return result

print(factorial(5))

Challenge 10: Fibonacci Series Using Function

def fibonacci(n):

    a = 0
    b = 1

    for i in range(n):
        print(a, end=" ")

        temp = a + b
        a = b
        b = temp
